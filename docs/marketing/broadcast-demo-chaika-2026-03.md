# Рассылка: «Демо-театр» / постановка «Чайка» (март 2026)

Вставьте текст в **Админка → Рассылки** (`/app/admin/broadcast`).  
Подстановки: `{name}` — имя получателя, `{email}` — адрес (подпись сервиса добавится автоматически).

## Рекомендуемые фильтры

| Поле | Значение | Зачем |
|------|----------|--------|
| Статус регистрации | **Доступ открыт** | только реально заходящие |
| Email подтверждён | **Да** | доставка |
| Тариф | **Все** | и Free, и Pro |
| Есть театр / Владелец | **Все** | и «зависшие» с пустым театром, и те, кто начал свой |
| Не включать админов | **Да** | по умолчанию |

Перед отправкой нажмите **«Показать получателей»** и проверьте число.

## Тема письма

```
{name}, откройте «Демо-театр» с постановкой «Чайка» — готовый план репетиции
```

Вариант короче:

```
Готовый план репетиции: «Демо-театр» в «Репетициях»
```

## Текст письма (скопировать в поле «Текст»)

```
Здравствуйте, {name}!

Вы регистрировались в «Репетициях» — сервисе для расписания репетиций, сцен и планов занятий. Многие начинают настройку своего театра и останавливаются на полпути: непонятно, как в итоге должен выглядеть готовый план.

Мы сделали учебный пример, чтобы это можно было увидеть сразу — без импорта текста, Telegram и длинных форм.

Что внутри примера:
— театр «Демо-театр» с постановкой «Чайка» (адаптация, разобранная по сценам);
— участники и роли (вымышленные имена, не реальная труппа);
— репетиция на ближайшую дату с уже сформированным планом;
— можно открыть «Поделиться планом» — Telegram, .ics или Google Календарь.

Демо не занимает лимит Free (один «настоящий» театр остаётся вашим).

Как открыть — один клик:
https://rehears.ru/app/overview?tryDemo=1

(Войдите под тем же email, что при регистрации.)

Если вы уже создавали свой театр:
1. Откройте ссылку выше — пример добавится рядом с вашим.
2. Или в приложении: раздел «Сейчас» — карточка «Посмотреть, как выглядит готовый план».
3. Или в меню «Театр» — «Добавить пример» / «К учебному примеру», затем выберите «Демо-театр».

Пример можно удалить одной кнопкой, когда перестанет быть нужен.

Если что-то не откроется — ответьте на это письмо или напишите в поддержку из приложения: Поддержка → новое обращение.

С уважением,
команда «Репетиции»
rehears.ru
```

## Проверка после отправки

- В истории рассылки: открытия и клики по ссылке `tryDemo=1`.
- На проде: зайти тестовым аккаунтом по ссылке из письма.

## Короткая версия (Telegram / пост)

```
В «Репетициях» есть «Демо-театр» с постановкой «Чайка»: сцены и репетиция с планом — за пару кликов, лимит Free не тратит.

Войти: https://rehears.ru/app/overview?tryDemo=1

В приложении: «Сейчас» → карточка с примером или Театр → «Добавить пример».
```
